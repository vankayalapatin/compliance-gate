# Docs

One line per current doc. Spec is `DATA-MODEL.md` plus `COMPANY-DATA.md`.

- `COMPANY-DATA.md` — the company the product runs for: identity, vendors, items, policies, history.
- `DATA-MODEL.md` — the two databases, what each holds, and how they link.
- `DECISIONS.md` — decision-by-decision record with reasons.
- `ERP-DESIGN.md` — mini-ERP table design record behind `Gate.Erp/`.
- `ONE-ORDER-RUNBOOK.md` — one order start to finish, every step done in the app.
- `company-kb/` — knowledge base and memo-to-rule design record.
- `archive/` — frozen early history, never a build reference (see `archive/README.md`).
